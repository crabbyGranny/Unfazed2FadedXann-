# Unfazed Studio (MVP scaffold)

This branch contains an initial mobile-first PWA scaffold for the Unfazed studio dashboard MVP.

What's included:
- Minimal PWA files
- AudioWorklet skeleton
- Universal preset schema
- Mobile knob component (React)

Files were added to start building the audio engine, import adapters, and mobile UI.

Next steps:
- Install dependencies and run the dev server
- Implement the audio engine and connect the UI to AudioWorklet
- Add import adapters and IndexedDB project storage
